A tiny deterministic program that writes a dishwasher's honest error report — every plate was loaded facing the wall, so it washed the wall instead — as one line of plain text, 121 characters, in the machine's own flat, put-upon voice.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable, e.g. `ENTRY_OUTPUT=entry.txt python3 main.py`).
